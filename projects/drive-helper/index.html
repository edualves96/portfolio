Drive Helper

Talk to Alexa and let a Claude agent work with your Google Docs: find a file, read it aloud, summarise it or edit it, with every change waiting for a spoken yes.

Role
Personal prototype
Status
Tested live against Google Docs
Limit
Answers inside Alexa's ~8 s window
Stack
  • Alexa Skills Kit
  • AWS Lambda
  • Node.js
  • Claude API
  • Google Drive API
  • Google Docs API
Build something like this

Demo

“Alexa, ask Drive Helper to add buy milk to my shopping list.”

“I'll add ‘buy milk’ to Shopping list. Should I go ahead?”

“Yes.”

“Done. It's at the end of Shopping list.”

The skill reads back what it is about to change and writes nothing until it hears a yes.

How it flows

  1. You speak

    “Alexa, ask Drive Helper to read my meeting notes.”

  2. Alexa skill

    Turns speech into text and back.

  3. AWS Lambda

    A Claude tool-use loop with four tools: search files, read a file, append to a doc, replace in a doc.

  4. Google Drive and Docs

    Through a service account that only sees files you share with it.

  5. Spoken reply

    Long documents are read in about one-minute chunks; say “next” to continue.

What you can say

You sayWhat happens
“Find my invoice from March”Searches Drive by name and content
“What does the contract say about payment terms?”Claude reads the file and answers
“Summarise the project brief”A spoken summary
“Add buy milk to my shopping list”Stages the edit, asks “Should I go ahead?” and writes only after “yes”

Safety

  • The service account only sees files explicitly shared with it, only Google Docs can be edited, and there's an optional allow-list of users.
  • Every edit is staged and needs a spoken yes; Google Docs version history is the undo button.
  • An offline test suite with mocked services, plus a live check against Google; runs on AWS Lambda or as an Alexa-hosted skill.
