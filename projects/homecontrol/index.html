HomeControl

One control panel for the living room: the TV, the TV box, three air conditioners and the robot vacuum, on the PC and on our phones, with the same setup everywhere.

Role
Personal project, used at home
Runs
Windows app and Android app
Devices

Demo

A stand-in for the real panel: the actual app shows our own home devices, so this page explains how it is wired instead.

Why

Five devices meant five apps, some of them only on one phone. I wanted one page that controls everything on the local network, works for both of us with our own layouts, and keeps working when the router gives a device a new address.

How each device is controlled

DeviceHow
Hisense TVMQTT over mutual TLS with a paired client certificate; Wake-on-LAN to switch it on
MEO TV boxAndroid TV Remote protocol v2, paired once
Two Midea ACsLocal network on port 6444, with the device key fetched once from the cloud
Samsung ACSmartThings API
RoombaiRobot cloud through its AWS IoT endpoint, since it refuses local control

What it does

  • Two profiles, each with a PIN and its own card names, order and hidden cards.
  • Every card has More options built from what the device itself reports: modes, sources, apps.
  • Finds devices again by MAC address when their IP changes.
  • Sync between the PC and the phones: each setting remembers when it changed and the newest wins, encrypted with a shared passphrase (PBKDF2 and AES-GCM) before it leaves a device.

Under the hood

PC
A Python aiohttp server on the machine and one HTML page in an Edge app window; a PyInstaller exe that stays in the tray while phones sync
Android
The same Python server running inside the phone with Chaquopy, shown in a WebView; a release-signed APK
Secrets
Windows Credential Manager on the PC, private app storage on Android; device keys are never written to the logs
